# Development

Everything a contributor needs, in the order you need it.

- **[Setup](setup.md)** — from a fresh clone to an app you can sign into. No
  credentials required.
- **[Testing](testing.md)** — the five test layers, coverage floors, guard
  tests, and how to run any of them.
- **[Workflow](workflow.md)** — how a change goes from a branch to production:
  the gate, the pull request, the promote.
- **[i18n](i18n.md)** — the key-based catalog, the two enforcement layers, and
  how to migrate a surface onto it.
- **[Analytics](analytics.md)** — PostHog conventions: event naming, the
  client/server pairs, identification, flags and experiments.
- **[Documentation](documentation.md)** — where a new document goes, and the
  conventions this tree follows.
- **[AI-assisted engineering](ai-assisted-engineering.md)** — most of this code
  was agent-written under review. The context budget, the executable rules,
  the permission model, and what was deliberately not built.

For product behaviour use [features/](../features/), not this section. For
system design use [architecture/](../architecture/README.md).

> This repository holds no backlog and no plans directory. Forward-looking work
> lives on a private board — see [docs/README.md](../README.md#conventions).
