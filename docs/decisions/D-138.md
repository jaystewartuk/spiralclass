# D-138. The product is SpiralClass, and identifiers that name a live external resource or stored client state keep `agendaprofe`

The product name is SpiralClass and the canonical origin is
`https://spiralclass.com`; `agendaprofe.com` is kept and 301s to it, except
`/api/stripe/*`. Any string that names a live external resource or persisted
client state was deliberately **not** renamed and must not be "finished" by a
sweep. That covers the Inngest app id, the R2 buckets, the OpenTofu state bucket,
the AWS SES IAM user and path, the docs Worker, the logical replication slots,
the GCP project and its service accounts, and browser storage keys.

## Why

The old name had a real cost. _Profe_ is a Latin American colloquialism for a
schoolteacher, opaque outside Spanish. _Agenda_ is a false friend: a diary in
Spanish, a meeting list in English. Together they named the calendar, the least
differentiated part of the product, for an audience that is global and
English-default ([D-72](./D-72.md)). The switching cost was at its lifetime
minimum: brand equity near zero, and no published app listing had made an
application id permanent.

Renaming a live identifier buys nothing a user can see, and each costs a data
migration or an outage:

- **Inngest app id** (`INNGEST_APP_ID = "agendaprofe"`). Renaming it orphans
  every registered function until the app is re-synced on production and
  preview. Events are still accepted and nothing runs. This caused the
  2026-07-07 total email and push outage.
- **R2 buckets** (`agendaprofe-{production-,preview-,}…` and
  `agendaprofe-tofu-state`). Bucket names are immutable and hold teacher
  photos, recordings and the OpenTofu state.
- **Docs Worker `agendaprofe`** (`wrangler.jsonc`). Renaming it in config
  creates a second Worker and leaves the custom domain bound to the first.
- **GCP project id** is immutable for the life of the project.
- **Browser storage keys** (`agendaprofe.*`). Renaming one silently drops what
  it held, such as a dismissed privacy notice.
- **AWS IAM user `agendaprofe-ses-sender`**, its `/agendaprofe/` path, and the
  replication slots `agendaprofe_region_{pub,sub}`.

## Options considered

- **Keep `AgendaProfe`** — chosen on 2026-08-27, on the grounds that the cost
  was "currently paid by nobody". It lost because that cost only rises, and the
  floor was the moment to pay it.
- **`teachlingua.com`** — the best purchasable candidate of about 55 checked
  against RDAP, `whois` and a registrar price API on 2026-08-27. RDAP alone gave
  false "unregistered" answers on `.co` and `.io` (`lingua.co` was active at a
  registrar). It was never weighed against `spiralclass`: the owner chose the
  name, and the domain was already registered.
- **Rename everything, live identifiers included** — see above.

## What it cost

- A rename across 934 files: brand copy, all three catalogs, the workspace
  names, `APP_URL`, every hostname, the docs site and the logo mark.
- Both Stripe webhooks failed for 1h36m (redirect at 15:52 UTC, noticed 17:28)
  because Stripe does not follow a 3xx. Stripe reported 0 delivered and 0
  failed that week, because there were no payers yet. The endpoints were moved
  by editing the existing destinations, which keeps their ids and signing
  secrets. The redirect rule, written as a `PUT` to the whole ruleset, also
  deleted the zone's two existing rules (checked afterwards and found
  redundant). The liveness monitor broke the same way that afternoon.
- Preview's `RESEND_FROM` stays on `updates.staging.agendaprofe.com`, which was
  never a verified Resend domain. That gap predates the rename and is not
  symmetric with production (`config/env/preview.runtime.env`).

## What it constrains

- **Do not rename an `agendaprofe` identifier as clean-up.** Each one is a
  migration with its own plan. The Inngest id is pinned by
  [`tests/inngest/app-id.test.ts`](../../apps/web/tests/inngest/app-id.test.ts);
  renaming it means changing the constant and re-syncing both environments in
  the same change. A legacy storage key is read beside its new one and never
  written ([`captions/notice.ts`](../../apps/web/src/lib/captions/notice.ts)).
- **Nothing that POSTs may point at `agendaprofe.com`.** A redirect is a failed
  delivery for Stripe, LiveKit webhooks and monitors.
- **No user-facing copy carries the old name** —
  [`i18n.test.ts`](../../packages/shared/src/i18n/i18n.test.ts) ("no
  user-facing copy carries the pre-D-138 product name"). The name is one
  constant ([`brand/name.ts`](../../packages/shared/src/brand/name.ts)).
- **The old palette is gone too** —
  [`retired-brand.test.ts`](../../apps/web/tests/config/retired-brand.test.ts)
  fails on its hexes and `rgb()` triples ([D-140](./D-140.md)).
- **Reopening the name**: re-cost it against what is free at that time. `agendaprofe.com`
  is retained, not released.

## How we got here

- **2026-08-23.** A strategic review held outside this repository kept the name
  "for a Spanish-speaking market".
- **2026-08-27.** That premise was withdrawn: the code already served teachers
  anywhere, in any of three UI languages, with `DEFAULT_LOCALE` `en`, and the
  one live teacher sold in English. The name was kept on other grounds, and the
  reopen trigger was set as "the first paying teacher who does not read
  Spanish". At that point the string appeared 2,152 times across 884 files.
- **2026-08-29.** Renamed on the owner's instruction, without that trigger
  firing. 329 occurrences across 45 distinct identifiers were preserved. Every
  identifier from the Inngest id down was caught **after** the bulk rename had
  changed it: the protect list came from a survey of hyphenated tokens, so it
  missed every resource name without a hyphen (`FLY_APP=` among them).
  `livekit.agendaprofe.com` was dropped the same day, after `LIVEKIT_URL` moved
  but before any class had connected on the new host (zero participant events
  in 72h).
- **2026-09-06.** The captions-notice key was found still on `agendaprofe.*`.
  It had been on neither the protect list nor the rename, and is now read as a
  legacy key.
- **2026-09-23.** Fly `agendaprofe`, on the original protect list, was
  destroyed when Cloud Run took production, and the Fly half of the tree went
  with it ([D-184](./D-184.md)). The mobile app was later deleted, and with it
  the mobile storage keys the protect list had covered.
