# D-116. Retire the no-local-tests policy — the full suite runs on the dev machine again

**What changed.** The "No local test suites" policy (in `CLAUDE.md` since
2026-07-06) is retired. The global `PreToolUse` hook that hard-blocked
`pnpm test`, `vitest`, `verify:local` and `test:e2e` on the
dev machine is **not recreated** on the new laptop — it lived in
`~/.claude/settings.json` on the old one, so no repo change removes it; this
decision records that it stays gone. Local runs of the unit, integration
(`pnpm verify:local`) and E2E suites are allowed and expected on the dev
machine. The standing instruction — `pnpm verify:push` (or `verify:local` for
a Tier 2 change) as the last step before every push — now applies to every
session on every machine, not just Claude Code Cloud sessions.

**Why it likely changed.** The policy's only premise was hardware: the suites
OOM-crashed the 8GB IdeaPad while the real compute lived on a separate box. As
of 2026-08-10 both halves of that premise are gone — that box was destroyed (the
thin-client reversal, recorded in the `kit` repo:
`decisions/thin-client-reversal.md`) and the dev machine is a 16GB M4
MacBook Air that carries all work locally. The direction was decided in `kit`
(`decisions/dev-toolchain.md` § "The no-local-tests hook — not recreated",
2026-08-10); this doc lands the policy change in the repo that carries the
policy, per the decisions-log convention that a reversal needs a `D-NN`, not
a silent edit.

**What was affected.**

- `CLAUDE.md` — the "No local test suites (IMPORTANT)" section replaced with
  a "Local test runs" section pointing here; the workflow
  passages that leaned on the hook ("blocks these for agents", "the human
  dev laptop OOM-crashes on the rest") reworded.
- **Nothing else.** Deliberately unchanged: `.githooks/pre-push` still runs
  `pnpm format:check` and nothing more — the 2026-07-06 redundancy argument
  (every non-format check runs server-side on the PR anyway) survives the
  OOM premise's death, so the hook stays light and CI stays the merge gate.

**Unresolved risks.** Whether 16GB actually holds `verify:local` alongside
the normal working set (emulator, Xcode, browser) is measured, not assumed —
the Stage 4 measurement in `kit/setup-macbook.md`, due before that machine's
2026-10-28 return decision. If the measurement fails, the answer is a
different machine, not this hook's return: the policy retirement stands
either way. Any older or borrowed machine (the 8GB IdeaPad, until its
~September handback) still cannot run the suites; nothing enforces that
beyond not doing it.
