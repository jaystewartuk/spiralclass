# D-87. Anthropic models are chosen per call shape, and a call that passes `effort` never runs on Haiku

Every call that passes `output_config.effort` resolves its model through
`anthropicModel()` in [`env.ts`](../../apps/web/src/lib/env.ts), which defaults
to `claude-sonnet-5`; the four short, structured calls — `SUMMARY_MODEL`,
`INSIGHTS_MODEL`, `BRIEF_MODEL` (`lib/lesson-notes/`) and `INTRO_COACH_MODEL`
(`lib/intro-video/coach.ts`) — are hardcoded to `claude-haiku-4-5` and pass no
`effort`. The Anthropic API rejects `effort` with a 400 on models before 4.6,
Haiku 4.5 included.

## Why

All five customer-facing surfaces ran on `claude-opus-4-8`, and cost was the
reason to move. The surfaces are not the same call. Material compose
(generate, refine, podcast script and the streamed variant, all in
[`lib/ai/anthropic.ts`](../../apps/web/src/lib/ai/anthropic.ts)) is long-form,
teacher-edited content on a paid feature: the only one that streams, the only
one at `max_tokens: 4096`, and the only one passing `effort: "medium"`. The
other four are short structured calls at 1024–2048 tokens, two of them forced
tool calls.

Published per-million-token prices at the time: Opus 4.8 $5 in / $25 out;
Sonnet 5 $3 / $15 (an introductory $2 / $10 ran to 2026-08-31); Haiku 4.5
$1 / $5.

## Options considered

- **Keep Opus on everything** — five times the price of Haiku on the four short
  calls, which have no monthly cap.
- **Haiku on all five** — committed first, and wrong: `effort` on Haiku is a
  400, so every material generation would have failed outright.
- **Split by call shape** — chosen. Sonnet 5 supports the full `effort` range,
  so compose kept `effort: "medium"` with no call-site change.

## What it cost

- The four Haiku surfaces got a weaker model on Pro features: flatter
  summaries, thinner briefs, less specific coaching. Unmeasured — there is no
  eval set, so a regression shows up as a teacher complaint. Prompts were tuned
  against Opus and not re-tuned.
- **The escape hatch is asymmetric.** `ANTHROPIC_MODEL` moves only
  `anthropicModel()`, with no deploy. The four constants ignore it; moving them
  is a code change and a release. And the env value is itself unchecked: setting
  it to a pre-4.6 model 400s every compose call.
- Haiku 4.5's context window is 200K against 1M; no current prompt comes close.
- Compose is capped per teacher; the four short surfaces are not.

## What it constrains

- **`effort` and Haiku never meet.** `tests/lib/env.test.ts`, "defaults to a
  model that supports output_config.effort", pins `anthropicModel()`'s default
  to an explicit effort-capable set. It covers the default only, not an
  `ANTHROPIC_MODEL` override.
- `tests/lesson-notes/summary.test.ts` pins `SUMMARY_MODEL`; each Haiku constant
  carries a comment saying it is safe only because it passes no `effort`.
  Adding `effort` to one of those calls means moving its model in the same
  change.
- Newer callers of `anthropicModel()` — homework AI review
  (`lib/homework/ai-review.ts`) and acquisition content
  (`lib/marketing/content.ts`) — pass no `effort` and inherit Sonnet 5; they
  could move to Haiku only by getting their own constant.
- Before treating "a cheaper model" as a cost lever, read the AI sections of the
  [cost playbook](../deployment/COST_PLAYBOOK.md).

## How we got here

- **Until July 2026.** Compose, summaries, insights, briefs and the intro coach each
  named `claude-opus-4-8`; the four short ones hardcoded their constant.
- **2026-07-19.** The move was first written as all five to Haiku and revised
  before production. It was not caught by testing: preview still ran the old
  backend, nothing tested the model–parameter pairing, and nothing in the types
  expresses it. The same 400 had already happened once, on live-caption
  translation: a Haiku call that set `effort` threw on every utterance, the
  route returned 502, and the teacher's subtitles toggle silently showed
  nothing. Caption translation no longer calls Claude.
- **Estimated effect**, against the worst-case envelope in the cost playbook,
  not observed usage: compose fell from about $0.15 to about $0.07 per
  generation, and a Pro teacher at the 100-generation cap from about $15 to
  about $7 a month; the four short surfaces fell five-fold.
- **Open.** One resolver for all five, checking effort-capability, so one
  setting can move the platform's tier without reopening the trap.
