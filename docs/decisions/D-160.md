# D-160. The gate runs the shared packages' suites — 1,265 tests were registered nowhere

**What changed.** `scripts/ci/steps.mjs` gains a `test-packages` step in the
`fast` tier: `pnpm --filter "./packages/*" test`. Until it landed, the only unit
step in the registry was filtered to `spiralclass-web`, so `packages/shared`
(1,196 tests across 71 files) and `packages/livekit-captions-agent` (69 across 9) were run by the workspace-wide `pnpm test` script and by **nothing the
pre-push hook, `pnpm gate` or `gate.yml` ever invoked**.

The filter is by path, not by package name. The failure below was a list that
did not grow; a list of two package names would have been the same failure
waiting for a third package.

## What it found the day it was added

Three assertions were red on `main`, and had been for a day.

- **A timezone defect in `weekdayLabels`.** The seven day names are formatted
  from UTC anchor dates, and `Intl.DateTimeFormat` formats in the **host** zone
  unless told otherwise. West of Greenwich every label slid back a day: a
  machine in Mexico City rendered Sunday's column as "Saturday". Fixed by
  passing `timeZone: "UTC"`.

  ⚠️ **This is the interesting half.** Production is UTC and the GitHub runner
  is UTC, so every machine that has ever run this code agreed it was correct.
  The one machine that would have caught it is **the operator's laptop** — the
  machine [D-119](./D-119.md) deliberately moved the checks onto — and the
  registry was not running the suite that contains the test.

- **Two stale assertions left by a sanitising pass.**
  `#1054` renamed a real
  teacher out of the tree and changed the fixture inputs in
  `initials.test.ts` and `booking-url.test.ts` without changing what they
  assert.

  ⚠️ **One of those assertions was the last place her real name survived in the
  tree**, three days before publication. It was not the only survivor: the same
  sweep found three more in `infra/oracle-box/`, which merged
  (`#1061`) _after_ the
  rename and had never been read by any scour.

## The rule

> **A suite that no step in the registry runs is a suite that is not run.**
> `pnpm test` existing is not the same as the gate running it.

This is the same rule [D-157](./D-157.md) states from the other direction. There
is one definition of green, in `steps.mjs`, and both producers inherit it in the
same commit — which is only worth anything if what the definition covers is
actually the tree.

## Accepted

- **No coverage floor on the packages.** The web project has an aggregate floor
  and a diff floor; these two get neither. A floor nobody set deliberately is a
  number to argue with later, and the tests existing and passing is the change
  that was missing.
- **A person's name is not a shape, so no gate can hold it.**
  `scripts/check-leaks.mjs` matches patterns and never values, deliberately
  ([D-158](./D-158.md)) — a checker that spelled out the name it was looking for
  would publish the name. The safeguard against that class of survivor is a
  search run outside this repository, and this decision does not change that.
- **The fast tier is three seconds slower.** That is the whole cost.
