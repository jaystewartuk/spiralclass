# D-01. Payment processor changed from Mercado Pago to Stripe

**What changed.** The product previously used Mercado Pago to take student payments; it now uses Stripe (Stripe Connect, with each teacher receiving funds directly into her own Stripe account).

**Why it likely changed.**

- Stripe's hosted checkout supports international cards out of the box, broadening which students can pay (relevant for students living outside Mexico).
- Stripe Connect onboarding is self-serve for the teacher; no platform-managed token refresh.
- One processor across card and (formerly) cash-voucher payments simplified the payment state machine.

**What was affected.**

- Public booking purchase flow.
- Teacher's "Payments" settings page (now Stripe Connect onboarding instead of Mercado Pago OAuth).
- Payment refund flow.
- Webhook handling.
- Privacy notice copy.

**Unresolved risks.**

- Some non-user-facing comments and migration files still mention Mercado Pago as historical context. They are not rendered to users.
- Teachers who built habits around Mercado Pago's seller experience may need re-onboarding documentation that does not yet exist in-product (see `TECH_DEBT.md`).
