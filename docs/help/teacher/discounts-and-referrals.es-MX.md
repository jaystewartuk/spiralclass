# Ofrece descuentos y referidos

## Propósito

Crea un código de descuento para posibles alumnos u opera un programa de referidos que premie a tus alumnos actuales por recomendaciones exitosas.

## Antes de empezar

- Debes tener sesión iniciada como profesor.
- Decide el descuento o la recompensa que puedes ofrecer antes de publicarlo.

## Pasos

### Crear un código de descuento

1. Abre **Descuentos**.
2. Elige **Crear código de descuento**.
3. Define el código, el porcentaje o monto fijo de descuento, y cualquier límite de vigencia o de usos.
4. Guarda y comparte el código tú mismo.

Los alumnos ingresan un código válido cuando pagan un paquete.

### Activar referidos

1. Abre **Referidos**.
2. Activa el programa.
3. Define el descuento para el amigo, la recompensa para quien refiere y el periodo de vigencia de la recompensa.
4. Guarda.

Los alumnos elegibles pueden entonces compartir su enlace o código personal de referido. La recompensa se crea solo después de que se confirma el primer pago del alumno referido.

## Consejos

- Agrega una vigencia o límite de usos a las ofertas por tiempo limitado.
- Comparte los códigos por los canales que ya usas; SpiralClass no envía promociones en tu nombre.
- Las recompensas de referidos se eliminan si el pago que las originó se reembolsa antes de usarse.

## Solución de problemas

**Un descuento no se aplica.** Revisa su vigencia, sus límites y si es válido para ese alumno y ese paquete.

**¿Por qué un alumno no recibió una recompensa de referido?** El pago del alumno referido debe ser una primera compra válida y debe estar confirmado primero.

## Preguntas

**¿Un alumno puede referirse a sí mismo?** No.

**¿Puedo usar un descuento y una recompensa de referido juntos?** La pantalla de pago aplica la oferta elegible según las reglas que se muestran ahí.
