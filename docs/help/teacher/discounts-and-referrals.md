# Offer discounts and referrals

## Purpose

Create a discount code for prospective students or run a referral programme that rewards current students for successful introductions.

## Before you start

- You must be signed in as a teacher.
- Decide the discount or reward you can afford before publishing it.

## Steps

### Create a discount code

1. Open **Discounts**.
2. Choose **Create discount code**.
3. Set the code, percentage or fixed discount, and any expiry or redemption limits.
4. Save and share the code yourself.

Students enter a valid code when they pay for a package.

### Turn on referrals

1. Open **Referrals**.
2. Turn the programme on.
3. Set the friend’s discount, the referrer’s reward, and the reward expiry period.
4. Save.

Eligible students can then share their personal referral link or code. A reward is created only after the referred student’s first payment is confirmed.

[Screenshot: Discount and referral settings]

## Tips

- Add an expiry or redemption limit to time-sensitive offers.
- Share codes through the channels you already use; SpiralClass does not send promotions on your behalf.
- Referral rewards are removed if the qualifying payment is refunded before the reward is used.

## Troubleshooting

**A discount does not apply.** Check its expiry, limits, and whether it is valid for that student and package.

**Why did a student not receive a referral reward?** The referred student’s payment must be a valid first purchase and must be confirmed first.

## Questions

**Can a student refer themselves?** No.

**Can I use a discount and a referral reward together?** The checkout screen applies the eligible offer according to the rules shown there.
