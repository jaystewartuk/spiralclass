# Prepara clases, materiales y tareas

## Propósito

Usa notas de clase y materiales de aprendizaje para preparar una lección, y luego asigna y revisa tareas.

## Antes de empezar

- Abre una clase reservada de un alumno.
- Algunas herramientas de IA requieren Pro y pueden tener un límite mensual.

## Pasos

### Agregar notas y contenido de clase

1. Abre la página de detalle de la clase.
2. Agrega pistas privadas de enseñanza y, si es necesario, notas visibles para el alumno.
3. Abre el panel de contenido de clase o materiales.
4. Escribe contenido, selecciona un material existente, sube un archivo o enlace, o genera un borrador si está disponible.
5. Revisa, edita y guarda.

Los alumnos siempre pueden ver el contenido de clase guardado. Solo ven las notas visibles para ellos poco antes y después de la lección.

### Construir tu biblioteca de materiales

1. Abre **Materiales**.
2. Elige **Agregar material**.
3. Escribe, genera, sube o agrega un enlace; selecciona un nivel y guarda.
4. Adjunta un elemento de la biblioteca a una clase o asígnalo desde el perfil de un alumno.

### Asignar y revisar tareas

1. Abre una clase y elige **Tareas → Agregar**.
2. Agrega un título, instrucciones, fecha límite y opciones de entrega; guarda.
3. Cuando un alumno entrega su trabajo, abre **Revisar**.
4. Agrega comentarios y una calificación opcional, y luego elige **Aprobar**, **Solicitar reenvío** o **Rechazar**.

## Consejos

- Mantén las pistas privadas separadas de las instrucciones visibles para el alumno.
- Guardar un material con un bloque de tarea o ejercicio puede crear un borrador de tarea; elimínalo si no quieres asignarlo.
- Una decisión de revisión no se puede cambiar después, así que revisa tus comentarios antes.

## Solución de problemas

**El alumno no puede ver la tarea.** Confirma que la asignación se guardó en la clase correcta.

**La generación con IA no está disponible.** Revisa tu acceso a Pro y tu límite mensual; si llegaste al límite, intenta más tarde.

## Preguntas

**¿Un alumno puede entregar tareas desde la web?** Sí. Abre la tarea desde la página de su clase y la entrega ahí.

**¿Puedo adjuntar más de un elemento de la biblioteca?** Sí, puedes elegir varios elementos existentes para una clase.
