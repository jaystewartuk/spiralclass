# Prepare classes, materials, and homework

## Purpose

Use class notes and learning materials to prepare a lesson, then assign and review homework.

## Before you start

- Open a student’s booked class.
- Some AI tools require Pro and may have a monthly limit.

## Steps

### Add notes and class content

1. Open the class detail page.
2. Add private teaching cues and, if needed, student-facing notes.
3. Open the class content or materials panel.
4. Write content, select an existing material, upload a file or link, or generate a draft if available.
5. Review, edit, and save.

Students can always view saved class content. They see student-facing notes only shortly before and after the lesson.

### Build your materials library

1. Open **Materials**.
2. Choose **Add material**.
3. Write, generate, upload, or add a link; select a level and save.
4. Attach a library item to a class or assign it from a student profile.

### Assign and review homework

1. Open a class and choose **Homework → Add**.
2. Add a title, instructions, due date, and submission options; save.
3. When a student submits work, open **Review**.
4. Add feedback and an optional score, then choose **Approve**, **Request resubmission**, or **Reject**.

## Tips

- Keep private cues separate from student-facing instructions.
- Saving material with a homework or exercise block may create a homework draft; delete it if you do not want to assign it.
- A review decision cannot be changed afterward, so check your feedback first.

## Troubleshooting

**The student cannot see homework.** Confirm the assignment was saved on the correct class.

**AI generation is unavailable.** Check your Pro access and monthly allowance, then try again later if you reached the limit.

## Questions

**Can a student submit homework on the web?** Yes. They open the assignment from their class page and submit there.

**Can I attach more than one library item?** Yes, you can choose multiple existing items for a class.
